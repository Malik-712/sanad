# Design reference

Put the HTML files exported from Claude Design in this folder (one file per artboard: Main, Home, Tree, TreeDesktop, Paste, About).

These files are a reference for building the app. They are not shipped. The values inside them (counts, percentages, pages, dates) are sample content and must not be copied into `data/`.

Session A writes `design/NOTES.md`, which maps each artboard to a route or component.
