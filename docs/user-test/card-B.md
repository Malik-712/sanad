# Card B — an isnād

Copied word for word from `data/hadiths/buniya-al-islam.json` (صحيح البخاري، ٨); source: https://shamela.ws/book/1681/19

**المهمة:** اذكر ثلاثة أحاديث على الأقل (الكتاب ورقم الحديث) ورد فيها هذا الإسناد نفسه أو ما يقاربه.

حَدَّثَنَا عُبَيْدُ اللهِ بْنُ مُوسَى قَالَ: أَخْبَرَنَا حَنْظَلَةُ بْنُ أَبِي سُفْيَانَ، عَنْ عِكْرِمَةَ بْنِ خَالِدٍ، عَنِ ابْنِ عُمَرَ ﵄ قَالَ: قَالَ رَسُولُ اللهِ ﷺ
