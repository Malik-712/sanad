## Recording instructions (for the owner)

1. **Prepare (5 min).** Open the live site in a new private window of Edge or Chrome. Set the window to full screen (F11) on a 1440 × 900 or larger screen, zoom 100 %. Close other tabs and notifications (Windows: Focus assist on).
2. **Record.** Windows: press **Win + Alt + R** (Xbox Game Bar) to start and stop; files go to `Videos\Captures`. Or use OBS Studio. Record each shot separately; retakes are cheap.
3. **Voice.** Record the voice-over separately in a quiet room (phone voice recorder is fine), one file per shot. Read slowly; if a shot runs long, cut words, not speed.
4. **Edit.** Windows **Clipchamp** (built in): put the clips in order, lay the voice files under them, trim each shot to its time above, add the shot 6 slide as a title card. Add Arabic subtitles if time allows.
5. **Check before upload:** total length ≤ 2:00 · no personal data on screen (no browser profile name, no e-mail) · no number other than those in shot 6 · the live link visible at the end.
6. **Export** 1080p MP4, and upload where the submission form asks.
